# Hosyond para Mac

[Descargar Hosyond-Mac.zip](https://github.com/johsian/hosyond-mac/releases/latest/download/Hosyond-Mac.zip)

Instalador de Hosyond Bridge para usar la pantalla Hosyond con rekordbox y la DDJ-FLX4.

**Requisitos:** Mac con Apple Silicon y macOS 15 o posterior, rekordbox instalado y una Hosyond con el firmware Wi-Fi ya cargado.

1. Descarga y descomprime el ZIP.
2. Conecta la Hosyond por su puerto USB-C de fábrica con un cable de datos.
3. Abre **Instalar Hosyond.app**, elige el puerto de la pantalla y configura tu red Wi-Fi de 2,4 GHz.
4. Concede a Hosyond Bridge permiso de Accesibilidad. Si macOS pide Grabación de pantalla o Red local, concédeselos también.
5. Conecta la DDJ-FLX4 por USB y usa rekordbox en **Performance → 2Deck Horizontal**. Cuando la Hosyond esté conectada por Wi-Fi, puedes alimentarla con un cargador o una batería.

La versión más reciente está firmada con Developer ID y notarizada por Apple. No necesitas una microSD para instalarlo.
